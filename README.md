## Learning Path

A practical progression through these **CTF labs**:

1. Start with **LupinOne Linux Enum** to build a systematic Linux enumeration workflow.
2. Continue with **Lupin's Linux Misconfigs** and **LupinOne Misconfig Hunt** to identify configuration weaknesses.
3. Study **Privilege Escalation Blueprint** to organize common Linux escalation concepts.
4. Practice **SUID Sleuth 2** and **LupinOne Capability Hijack** to understand permission and capability-related risks.
5. Explore **Cron: Key to the Kingdom** to examine scheduled-task security.
6. Move to **LupinOne Access Chain** to connect multiple findings into an access path.
7. Practice **LupinShell: Reverse Pathways** and **Shell Stab: Session Shift** for shell-session concepts.
8. Finish with **Shellcraft: Linux Basics to Root** for a broader Linux-to-root challenge.
9. Use **Credential Echo** to reinforce credential-security awareness.

Difficulty levels are not inferred unless explicitly stated in the supplied lab information.

## How to Use the Labs

1. Open a lab through its direct link.
2. Read the objectives and environment requirements.
3. Use only the provided CTF environment or systems where you have explicit authorization.
4. Begin with enumeration rather than assumptions.
5. Document permissions, capabilities, scheduled tasks, files, services, shells, and credential-related findings.
6. Analyze the root cause of each weakness.
7. Consider defensive controls that could prevent or detect the behavior.
8. Keep all testing inside the authorized environment.
